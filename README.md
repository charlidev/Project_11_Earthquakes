
# Project 11 - Earthquakes

## Seismic Intelligence Lakehouse

An end-to-end Data Engineering project integrating the
USGS Earthquake API with Azure Databricks.

### Architecture
- Python API Ingestion
- Azure Data Lake Storage Gen2
- Azure Databricks
- Delta Lake
- Medallion Architecture
- Incremental Data Loading
- CDC-like Processing
- SCD Type 2
- Databricks Workflows
- GitHub Actions CI/CD
- Power BI

### Environments
- DEV
- TEST
- PROD

### Data Source
USGS Earthquake Catalog API

https://earthquake.usgs.gov/fdsnws/event/1/
